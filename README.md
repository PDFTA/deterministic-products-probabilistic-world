# Deterministic Products in a Probabilistic World

A product oriented guide to LLMs using Pydantic.

## Running the presentation

The presentation is a single `index.html` file. Because browsers block local font loading from `file://` URLs, serve it over HTTP:

```bash
python3 -m http.server 8765
```

Then open [http://localhost:8765](http://localhost:8765) in your browser.

## Navigation

| Key | Action |
|-----|--------|
| `→` / `Space` | Next slide |
| `←` | Previous slide |
| `Home` | First slide |
| `End` | Last slide |
| `F` | Toggle fullscreen |

You can also click the **right half** of the screen to advance and the **left half** to go back.
