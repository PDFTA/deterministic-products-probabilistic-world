Probabilistic Systems

Using probabilistic systems

  • LLMs are probabilistic in nature
  • For the first time in computing history we're building large-scale systems that are probabilistic in nature
  • We're still figuring out best practices

What is a probabilistic system?

A system whose output is not fully determined by its input — the same input can produce different outputs on different runs, governed by a probability distribution.
  • Deterministic: same input → always the same output
  • Probabilistic: same input → output drawn from a distribution

How do LLMs generate a response?

P(next token | context) → sample → repeat until stop
  • LLMs are Bayesian, In Expectation — not in Realization
  • P(θ) represents a prior over tasks induced by pretraining data
  • Each token is sampled from a probability distribution over the vocabulary

Curse of Dimensionality

  • Measuring distance from a point gets increasingly difficult as dimensions increase
  • LLMs operate in extremely high-dimensional space
  • This makes evaluating "how close" an output is to the ideal extremely hard

Markov Decision Processes

My mental model for LLMs

  • States (S): A set of possible states the environment can be in
  • Actions (A): A set of actions the agent can take
  • Transition Probability (P): The probability that action a in state s will lead to state s'
  • Reward (R): The immediate reward after transitioning from s to s' due to action a
A mathematical framework for modeling sequential decision-making where outcomes are partly random and partly under the control of a decision maker.

What this means for us

  • In an LLM there's a probability that any token can be predicted next
  • That's a huge distribution to evaluate — we care about the sum of all next tokens until the stop point
  • It's a much higher distribution problem: P(Xn)
How do we validate P(y'n+1)?

Structured Outputs & AI

What is a structured output?

  • A response to an LLM prompt that fits a given format
  • Usually a JSON schema
{
  "Name": "tiddles",
  "Species": "cat"
}

What is Pydantic?

Most popular data validation library in Python

class Fruit(BaseModel):
    name: str
    color: Literal['red', 'green', 'yellow']
    weight: Annotated[float, Gt(0)]
    bazam: dict[str, list[tuple[int, bool, float]]]

Custom Validators

def is_even(value: int) -> int:
    if value % 2 == 1:
        raise ValueError(f'{value} is not an even number')
    return value


class Model(BaseModel):
    number: Annotated[int, AfterValidator(is_even)]

Other OSS frameworks are available

How do we validate P(y'n+1)?

P(y'n+1 | x, θ)
  • We can't validate every possible output — the space is too large
  • We need to constrain the output space first
  • Structured outputs are how we get a handle on this

What is the unit of work?

  • We don't care about each individual token
  • We care about our structured output as a whole
  • This shifts our evaluation unit: tokens → structured objects

Putting the "science" in data science

Karl Popper — Falsificationism: A hypothesis is scientific only if it can, in principle, be proven false. If you can't define what failure looks like, you can't evaluate success.
  • Define what a bad output looks like before you build
  • Write evaluations as falsifiable criteria
  • Iterate based on evidence, not intuition
